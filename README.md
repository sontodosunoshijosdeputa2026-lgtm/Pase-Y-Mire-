# Pase y Mire

Plataforma de juegos con créditos virtuales.

## Estado

Proyecto iniciado desde cero.

## Tecnología

- HTML
- CSS
- JavaScript
- Supabase

## Características previstas

- Tragamonedas
- Créditos virtuales
- Perfiles de usuario
- Billetera virtual
- Juegos destacados
- Favoritos
- Diseño mobile-first
- Catálogo dinámico desde Supabase

## No incluidos

- Rankings
- Historial de partidas visible
- Partidas/resultados como sección independiente
- Conversión de créditos virtuales a dinero
